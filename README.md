# AI-101L Laboratory Portfolio (`ai-lab-portfolio`)

**Course:** Introduction to Artificial Intelligence (AI-101L)  
**Instructor:** Dr. Muhammad Awais  

## Labs Included

* **`lab01/`** - Environment Setup: Anaconda, Jupyter Notebook, Pandas Inspection (`inspect.py`), and Git
* **`lab02/`** - Web Scraping (`BeautifulSoup`), NLP Feature Engineering (`spaCy`, `TextBlob`), and EDA (`TF-IDF`)
* **`lab03/`** - Transforming Textual (`CountVectorizer` BoW) and Image Data (`Pillow` Grayscale & Flattening) into Machine-Understandable Format
* **`lab04/`** - Supervised Learning with Scikit-Learn: Simple Linear Regression, Multiple Linear Regression, and Logistic Regression
